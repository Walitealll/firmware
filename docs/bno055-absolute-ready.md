В текущей основной прошивке после START кадр `0x03` отправляется и при
`CALIB_STAT.sys=0`, если оба BNO выдают пригодные кватернионы. Калибровка
и `north_reference` показываются в отладке. Для запуска используются
аппаратный сброс обоих BNO и встроенные генераторы. Ниже описана предыдущая
реализация с ожиданием калибровки и её проверка на плате.

## Что делает BNO055

В NDOF чип сам рассчитывает ориентацию относительно гравитации и магнитного поля Земли. Профиль калибровки можно не сохранять: тогда после каждого сброса/включения нужно вновь выполнить условия автоматической калибровки. Неподвижный старт сам по себе не заменяет калибровку магнитометра и акселерометра. Профиль содержит поправки датчиков и радиусы, а не последний угол или позу включения. Его сохранение ускоряет повторную готовность, но не является обязательным условием абсолютного NDOF.

Источник: Bosch BNO055 DS rev.1.8, разделы 3.3.3, 3.11 и 3.11.5. Текст даташита проверен в локальной копии `C:/Users/Oleg/Desktop/project/pcb_review/bno055.txt`. [Официальный PDF](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bno055-ds000.pdf).

## Изменения основной программы

- В `config/fw_config.h` `FW_BNO_USE_EXT_CRYSTAL_INT=0`, `FW_BNO_USE_EXT_CRYSTAL_EXT=1`. Оба резонатора физически установлены, но на проверяемой плате запустился только кварц external. Это явная настройка по результату проверки, без программного скрытия ошибок переключения. Внешний источник выбирается в CONFIG; после исходной выдержки 700 мс код опрашивает бит 0 `SYS_CLK_STATUS` до его сброса, затем проверяет CLK_SEL. Общий программный предел ожидания — 2000 мс. Сбой I2C, таймаут и завершившийся выбор неверного источника сохраняют диагностические факты.
- В `App/FW_angle.c` каждый снимок включает сырые Euler и один блок `CALIB_STAT..SYS_TRIGGER`. Из того же блока берутся калибровка, OPR_MODE, SYS_STATUS, SYS_ERR, UNIT_SEL и источник тактирования. По сравнению с прежним циклом отдельное чтение каждого статуса не добавляется.
- `g_bno_quality_internal/external` публикуют результат последней попытки чтения. Готовность требует NDOF, SYS_STATUS=5, SYS_ERR=0 и правильного UNIT_SEL. Для первого допуска все четыре поля CALIB_STAT должны быть равны 3. После этого допустимы оценки 2 и 3. `fully_calibrated` показывает, равны ли все оценки 3 в текущем снимке.
- `north_reference` отдельно отражает работающий NDOF с ненулевым CALIB_STAT.sys. Он не подменяет полную калибровку и не доказывает отсутствие магнитных искажений.
- Сырые `g_eul_internal/external` остаются доступными до полной калибровки. Их ранние значения не следует считать готовыми абсолютными углами. При ошибке I2C последние удачные Euler/калибровка сохраняются, но `io_ok`, `ready` и общий флаг готовности сбрасываются.
- `g_angle_ready=1` означает, что получен пригодный угол сгибания. Для этого нужны готовность обоих BNO, заданные оси крепления и кватернионы ненулевой длины.
- `FW_angle_window` возвращает -1 при ошибке I2C, -2 при ожидании калибровки, -3 при незаданных осях и -4 при нулевом кватернионе. При ошибке `FW_sync_poll` пропускает измерительный кадр. Активный START продолжает отправку автоматически при появлении готового угла.
- Угол в кадре вычисляется по направлениям продольных осей двух модулей в общей системе NDOF. Положение при включении может быть согнутым. Геометрия крепления описана в [документации расчёта угла](knee-angle.md).

## Проверка на плате

1. Загрузить новый `build/firmware.elf` через конфигурацию `BNO055 firmware`, нажать Resume. Новый запуск Debug сбрасывает BNO и вновь начинает калибровку.
2. В Live Expressions смотреть `g_angle_ready`, обе `g_calib_*` и обе `g_bno_quality_*`. Ожидаемые `sys_trigger`: internal `0x00`, external `0x80`; в `sys_clk_status` бит 0 должен быть 0. Структуры `s_fact_*` показывают только инициализацию; `g_bno_quality_*` обновляются во время опроса.
3. Дать обоим датчикам неподвижно полежать для калибровки гироскопов. Для акселерометров выполнить шесть устойчивых ориентаций с паузами по несколько секунд; для магнитометров — плавные повороты по разным осям. Эти действия нужны после каждого сброса без сохраненного профиля.
4. Дождаться SYS/GYR/ACC/MAG=3 у обоих и `g_angle_ready=1`. Можно остановиться в любом месте и выполнить memory-only снимок `source C:/Users/Oleg/Desktop/project/frimware/scripts/bno055-firmware-snapshot.gdb`: вызовов функций и изменений BNO в нем нет.
5. Сравнить heading при одинаковом положении корпусов после калибровки. Затем повторить включение в разных положениях и калибровку. Если после готовности показания не совпадают в одинаковой ориентации, это не следует исправлять автоматическим обнулением при включении: нужно проверять оси крепления, магнитное окружение и данные внутренних сенсоров.

Внутренний акселерометр ранее показывал значения около ±39,2 м/с² на неподвижной плате, а CALIB_STAT.accel оставался 0. Эта аномалия не устранена текущим изменением. Если она сохраняется, полная готовность может не наступить; ожидание в таком случае намеренное и будет видно по `wait_reason`. Значения CALIB_STAT=3 сами по себе также не сертифицируют точность в произвольном магнитном окружении.

## Причины ожидания

`wait_reason` — битовая маска; несколько значений складываются побитовым OR.

| Значение | Причина |
| --- | --- |
| `0x0001` | Еще не выполнено первое чтение после инициализации |
| `0x0002` | Ошибка I2C или пара шина/адрес не инициализирована |
| `0x0004` | Текущий режим не NDOF |
| `0x0008` | Fusion еще не работает |
| `0x0010` | SYS_ERR не равен 0 |
| `0x0020` | UNIT_SEL не совпадает с настройкой |
| `0x0040` | Калибровка SYS ниже порога |
| `0x0080` | Калибровка гироскопа ниже порога |
| `0x0100` | Калибровка акселерометра ниже порога |
| `0x0200` | Калибровка магнитометра ниже порога |

## Подтверждение выбора часов на плате

- Снимок после `4441 INITIALIZATION FW_angle.internal ERR CLOCK`: internal I2C1 `0x28`, PAGE_ID=0, CHIP_ID=`0xA0`, OPR_MODE=`0x10` (CONFIG), SYS_CLK_STATUS=`0xB8`, SYS_TRIGGER=`0x00`, SYS_STATUS=0, SYS_ERR=0. Все чтения успешны. Бит 0 в `0xB8` равен 0, несмотря на ненулевые зарезервированные биты.
- Повторная запись `SYS_TRIGGER=0x80` у internal спустя время после загрузки, в подтвержденном CONFIG: запись `FW_HW_OK`, через 1 и 2 секунды `SYS_CLK_STATUS=0xB8` и `SYS_TRIGGER=0x00`. Кварц не выбран даже при поздней записи; одного увеличения паузы в начале прошивки недостаточно. Это не определяет, неисправен ли сам резонатор, его обвязка, соединения или вход BNO.
- Та же проверка external I2C2 `0x29`: запись `FW_HW_OK`, через 1 и 2 секунды `SYS_CLK_STATUS=0xB8` и `SYS_TRIGGER=0x80`. Внешний кварц выбран устойчиво. После проверки оба датчика возвращены к исходным `SYS_TRIGGER=0x00` и CONFIG; сбросы не выполнялись.
- Bosch BNO055 DS, §5.5.1: после команды выбора внешнего источника нужно дождаться `ST_MAIN_CLK=0` и проверить CLK_SEL. При неподходящем сигнале кварца чип возвращается к внутреннему источнику и сбрасывает CLK_SEL. NDOF может работать с внутренним источником. Смена источника не заменяет калибровку.
- Для текущего опроса часов добавлены тесты маски `0x01` на регистре `0xB8`, запуска с задержкой больше 700 мс, таймаута, отказа внешнего кварца и ошибки I2C.
